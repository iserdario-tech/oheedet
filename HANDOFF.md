## 1. Что это за проект

**oheedet** — снижение веса **без спортзала**, только за счёт питания и образа жизни, на
подтверждённой науке. Конечный продукт — **PWA**, которое собирает персональное недельное меню
(что есть, сколько, когда) под условия человека: аллергии, нелюбимая еда, посуда/техника, бюджет,
режим «на двоих» (пользователь + жена).

**Честная рамка (D-001):** никаких «жиросжигающих продуктов». Единственный механизм — **дефицит
энергии**; всё остальное (белок, клетчатка, плотность калорий, сон, среда) — рычаги, которые
делают дефицит **незаметным и удерживаемым**.

**Не путать:** соседний проект `~/Desktop/pospat` — это про сон/бодрость, отдельная тема.

## 4. Наука в одном экране (детали — в findings.md)

- **Единственный механизм — дефицит.** При равных калориях тип диеты почти не влияет на потерю
  жира (метаболические палаты) `[S-001, S-003]`. Решает **приверженность**, а не диета `[S-006…S-009]`.
- **Почему «без спорта» — рабочий путь:** тело компенсирует нагрузку (тренировки дают ~30% от
  ожидаемого прироста расхода) `[S-004]`; питанием дефицит создаётся легко.
- **Сытость без подсчёта:** белок 1.2–1.6 г/кг `[S-012, S-013]`; клетчатка ≥30 г `[S-015]`; низкая
  калорийная плотность (даёт больше потерю при **меньшем** голоде) `[S-017, S-018]`; минимум
  ультра-переработки (скрытые +508 ккал/д) `[S-016]`; долой жидкие сахара `[S-019, S-020]`.
- **Внефудовые рычаги:** сон (недосып +253 ккал/д; продление сна −270 ккал/д) `[S-031, S-032]`;
  порции/посуда (±12–16% калорий) `[S-040]`; вода перед едой `[S-036, S-037]`; алкоголь `[S-038]`;
  стресс `[S-033]`. Микробиом — пока без доказанной практики `[S-035]`.
- **Тайминг:** IF не лучше обычного дефицита `[S-022, S-023]`; завтрак необязателен `[S-025]`;
  **но поздняя еда реально мешает** (↑голод, ↓расход) `[S-026]`.
- **Откат:** гормоны голода после похудения год не возвращаются `[S-045]`; метаболическая
  адаптация реальна, но её роль преувеличена `[S-047, S-048]`. Удерживают — режим + мониторинг `[S-049]`.
- **Поведение:** трекинг — самый доказанный рычаг `[S-041, S-042]`; привычки «если-то» `[S-043]`.
- **Безопасность:** темп 0.5–1 кг/нед, не VLCD `[S-052]`; скрининг лекарств/состояний `[S-055]` и
  РПП `[S-058, S-059]`; GLP-1 мощно, но это медицина `[S-056, S-057]`.
- **Мифы (не обещаем):** detox, «разгон метаболизма», спот-редукция, БАДы `[S-061…S-065]`.

## 5. Приложение: как устроено и как запустить

**Стек (осознанно ленивый):** vanilla ES-модули, **ноль зависимостей, ноль сборки**, тесты на
встроенном `node --test`. PWA без бэкенда и аккаунтов; данные — в localStorage.

```
app/
  index.html      онбординг-форма + переключатель темы
  app.js          оркестрация: профиль → цели → safety → план → рендер
  render.js       рендер недели/рецептов/покупок
  tracker.js      отметки по дням + вес
  tokens.css      ДИЗАЙН-ТОКЕНЫ (индиго #5E6AD2, свет/тьма)
  styles.css      компоненты через токены
  manifest.json   PWA
  data/recipes.json   16 рецептов (макросы на порцию)
  src/targets.js  TDEE (Mifflin-St Jeor) → калории/белок/клетчатка/темп
  src/safety.js   guardrails: пол калорий, скрининг → «к врачу»
  src/planner.js  фильтры (аллергии/посуда/бюджет/нелюбимое) + жадный набор недели
  src/couple.js   режим «на двоих» (общий ужин, порции под каждого)
  src/grocery.js  список покупок + прикидка бюджета
  test/*.test.js  14 тестов
```

**Запуск:**
```bash
cd /Users/iserdario/Desktop/oheedet/app
python3 -m http.server 8123     # нужен http: приложение делает fetch рецептов
# открыть http://localhost:8123
```

**Тесты:**
```bash
cd /Users/iserdario/Desktop/oheedet/app && node --test
# ожидается: pass 14, fail 0
```

**Ключевые правила, зашитые в движок:** дефицит 550 ккал/д; темп ≤1 кг/нед; белок 1.6 г/кг
(реф-вес); клетчатка 30 г; распределение калорий 30/40/30; ужин в 18:00; пол калорий — 1200 (ж) /
1500 (м); при флагах скрининга дефицит смягчается и показывается баннер «к врачу».

## 6. Решения (полностью — в DECISIONS.md)

- **D-001** Честная рамка: только дефицит, никаких чудо-продуктов.
- **D-002** Сначала научная база, приложение — потом. *(выполнено)*
- **D-003** Фокус — питание и образ жизни, без спортзала.
- **D-004** Только peer-reviewed, иерархия доказательности.
- **D-005** Безопасность — часть продукта.
- **D-006** Объём MVP: ядро = генератор недельного меню. **В v2:** дневник/сканер, гликемическая
  персонализация, интеграция сна (стык с pospat), GLP-1, аккаунты.
- **D-007** Платформа — **PWA** (подтверждено пользователем; Telegram-бот отклонён).
- **D-008** v1 без ручного подсчёта калорий (только трекинг-лайт «съел/заменил» + вес).

## 8. Известные ограничения и «долги» (честно)

- **UI не проверен в браузере вручную.** Логика покрыта тестами (14/14) + сквозными прогонами на
  реальных данных, но клики по интерфейсу не гонялись — мешала неверная привязка preview (§0).
  **Первое, что стоит сделать в новом чате.**
- **`ponytail:`-пометки в коде** (осознанные упрощения с названным потолком):
  - `planner.js` — жадный набор 30/40/30 + добор белка; при систематическом промахе → оптимизатор (ILP).
  - `planner.js` — стемминг «нелюбимого» обрезкой окончания (ловит капуста→капустой); не полная морфология.
  - `couple.js` — делится только ужин; полный двойной планировщик — по запросу.
  - `grocery.js` — стоимость = прокси `rank(costTier) × qty`, не реальные цены.
  - `app.js` — второй профиль пары — заглушка (вес −15 кг); нужен нормальный ввод.
  - `targets.js` — одна формула (Mifflin-St Jeor).
  - PWA service worker (офлайн) отложен.
- **Рецептов 16** — работает, но для разнообразия стоит нарастить (чистый контент, движок готов).
- **Источники с пометкой `Note:`** в sources.md требуют сверки DOI/авторов: S-006, S-014, S-015,
  S-023, S-024, S-027, S-033, S-042, S-046, S-050 и др. — база рабочая, но перед публичным
  использованием сверить.
- Побочные дни в плане могут превышать целевой калораж на ~5–8% из-за добора белка — в пределах
  допуска ±15%, но это ожидаемый потолок жадного алгоритма.
