# GLOSSARY — термины проекта

> Краткие рабочие определения. Уточняются и дополняются по ходу ресерча; при наполнении
> [findings.md](docs/research/findings.md) ключевые термины получат ссылку на источник.

| Термин | Что значит |
|--------|-----------|
| **Энергетический баланс** | Соотношение поступивших и потраченных калорий. Дефицит → снижение веса, профицит → набор. |
| **Дефицит калорий** | Когда тратишь энергии больше, чем получаешь с едой. Единственный прямой механизм снижения веса. |
| **TDEE** | Total Daily Energy Expenditure — суммарный расход энергии за сутки. |
| **BMR / RMR** | Базовый / в покое обмен веществ — энергия на поддержание жизни в покое (самая большая часть TDEE). |
| **TEF** | Термический эффект пищи — энергия на переваривание (у белка выше всего). |
| **NEAT** | Non-Exercise Activity Thermogenesis — расход на бытовую активность (ходьба, фиджетинг), не тренировки. |
| **Плотность калорий (energy density)** | Калорий на грамм еды. Низкая плотность (овощи, супы) даёт объём и сытость при меньших калориях. |
| **Ультра-переработанная еда (UPF, NOVA)** | Промышленно переработанные продукты; в РКИ провоцируют переедание при равных калориях. |
| **Гликемический индекс / нагрузка (GI/GL)** | Насколько продукт поднимает сахар крови; GL учитывает ещё и порцию углеводов. |
| **Клетчатка** | Неперевариваемые углеводы; дают сытость, замедляют опорожнение желудка, кормят микробиом. |
| **Сытость (satiety) / насыщение (satiation)** | Satiety — как долго не хочется есть после еды; satiation — насыщение в процессе приёма пищи. |
| **Грелин / лептин** | Грелин — «гормон голода»; лептин — сигнал сытости/запасов жира. |
| **GLP-1, PYY, CCK** | Кишечные гормоны сытости; мишень новых препаратов (семаглутид и т.п.). |
| **Метаболическая адаптация (адаптивный термогенез)** | Замедление обмена при похудении сильнее ожидаемого; сопротивляется снижению веса. |
| **Set point / settling point** | Гипотезы о «весе, к которому тянет тело»; объясняют откат веса. |
| **Интервальное голодание (IF) / TRE / ADF** | Ограничение окна еды (TRE, напр. 16:8) или голодание через день (ADF). |
| **VLCD** | Very Low Calorie Diet — очень низкокалорийная диета (<800 ккал/день), только под контролем врача. |
| **NWCR** | National Weight Control Registry — реестр людей, удержавших большой сброс веса; источник практик удержания. |
| **NOVA** | Классификация продуктов по степени промышленной переработки (1–4). |
| **Самонаблюдение (self-monitoring)** | Ведение дневника еды/веса; самый доказанный поведенческий рычаг похудения. |
| **Уровень доказательности** | Ранг источника: мета-анализ/сист. обзор > РКИ > когорта > поперечное > механистика > мнение. |
