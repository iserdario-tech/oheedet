# oheedet

Проект про **снижение веса без спортзала** — за счёт питания и образа жизни, опираясь
только на подтверждённую науку. Конечная цель — приложение, которое подбирает под
конкретного человека (и пару) недельное меню с учётом его условий: продукты, посуда,
аллергии, нелюбимая еда, порции и тайминг.

> **Честная рамка.** Мы не обещаем «жиросжигающих продуктов» и чудо-диет. Единственный
> механизм снижения веса — устойчивый дефицит энергии. Всё остальное (белок, клетчатка,
> плотность калорий, сон, среда) — это рычаги, которые делают дефицит **незаметным и
> удерживаемым**, без силы воли и без лишних физнагрузок.

## Порядок работы (фазы)
1. **Научная база** — собрать и систематизировать подтверждённые исследования по
   снижению веса (мета-анализы > РКИ > когорты). Наполняется сейчас. ← мы здесь
2. **Дизайн приложения** — движок недельного меню под условия пользователя + режим
   «на двоих». Проектируем после базы.
3. **Сборка** — реализация приложения по спеку. В самом конце.
